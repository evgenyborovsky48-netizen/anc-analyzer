Bluetooth & phone tips

  • Use the phone's own microphone, not the speaker's. Opening a Bluetooth speaker's mic switches it into hands-free mode (mono, ~8–16 kHz, filtered), which ruins measurements and audio quality.
  • Output goes to the connected Bluetooth speaker automatically; phone browsers can't pick an output device.
  • Bluetooth adds ~150–300 ms of delay. That's fine for analysis and for steady tones, but it rules out cancelling anything that changes.
  • Small Bluetooth speakers barely play below ~100–150 Hz; deep hum needs a woofer.
  • Levels are relative (dBFS), not calibrated dB SPL. For real SPL, use a calibrated mic such as the UMIK-1.
  • Save WAV keeps the raw recording, so you can run it through the FxLMS simulation (anc_sim.py) later.
  • Install: Android Chrome → ⋮ → Add to Home screen / Install app. iPhone Safari → Share → Add to Home Screen. After the first visit it works offline.
