# ANC Noise Analyzer

Phone web app (PWA) for the Active Noise Control project. It measures machine noise with the phone microphone, finds the tones, scores how well each one could be cancelled by ANC, and estimates the possible reduction in dB(A). It includes an anti-tone generator for testing through a Bluetooth speaker, and can save recordings as WAV.

All processing runs on the device. No audio or data is uploaded.

**Install:** open the site → Android Chrome: ⋮ → *Install app* · iPhone Safari: Share → *Add to Home Screen*.
